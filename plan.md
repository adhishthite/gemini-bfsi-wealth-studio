### ✅ What we DID crack (so integration is de-risked once entitlement exists)
The avatar config wire schema differs by path (SDK only camelCases the outer key, not inner fields):
- **Vertex path:** `avatarConfig: { avatar_name: "Jay" }` (built-in) — matches the user guide; SDK
  `types.AvatarConfig(avatar_name=...)` is correct here.
- **AI Studio (mldev) path:** built-in `avatar_name` is **rejected**; mldev uses an **image-based custom avatar**:
  `avatarConfig: { referenceImage: { data: <base64 PNG>, mimeType: "image/png" } }` (704×1280, 9:16).
  Reverse-engineered by field-probing the server's "Unknown name … at 'setup.avatar_config…'" errors.
- Backend will support **both** behind config (`AVATAR_TRANSPORT=vertex|aistudio`) with a key-rename shim for the
  mldev inner fields, and an **audio-only / static-avatar fallback** so the demo always runs.
